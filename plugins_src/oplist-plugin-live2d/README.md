# Live2D 动态看板娘插件 (Live2D Companion Plugin for OpenListNext)

为 OpenListNext 打造的交互式 Live2D 看板娘扩展插件。

## ✨ 特性

- 🎭 **多模型一键切换**：内置药水娘 (Pio)、静久 (Shizuku)、小春 (Koharu)、狗狗 (Wanko)、白猫 (Tororo)、黑猫 (Hijiki) 等多款经典 Live2D 角色。
- 💬 **智能交互对话**：支持点击互动、问候语提示、每日一言随机趣味问答。
- 🧭 **路由与页面联动**：进入管理后台或切换目录时触发专属情景对话。
- 🌗 **深色/浅色模式自适应**：气泡对话框与悬浮工具栏完美适配系统主题。
- 🙈 **一键隐藏与唤出**：支持贴边最小化与随时呼出。

## 📦 安装方法

1. 在 OpenListNext 管理后台进入「插件管理」页面。
2. 点击右上角「安装插件」，在「ZIP 压缩包上传」中选择 `oplist-plugin-live2d.zip` 文件。
3. 点击确认安装即可立即在页面角落唤出看板娘！
